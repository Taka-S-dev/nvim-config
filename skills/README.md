# skills

この設定の機能を、AI エージェントから使うためのスキル。`name` と
`description` を持つ共通の書式の `SKILL.md` なので、この書式を読める
エージェント（Claude Code、Codex、GitHub Copilot など）で使える。

| スキル | 使う機能 |
|---|---|
| `nvim-trace` | 調べたコードの道筋を、手順ごとの解説付きで Neovim に出す（`:h cfg-trace`） |
| `nvim-debug-lines` | 実行して確かめるためのデバッグ行を、Neovim を通して入れて消す（`:h cfg-debug-lines`） |

スキルを使うのは、この設定のリポジトリではなく、調べているほかの
リポジトリで作業するとき。なので、エージェントの個人のスキルのフォルダに
置く。

## 入れ方

`bin/link-skills.cmd` を実行すると、ここの各スキルへのリンク（ジャンクション）
を、次のフォルダに作る。

- `~/.claude/skills/`（Claude Code）
- `~/.codex/skills/`（Codex）
- `~/.agents/skills/`（GitHub Copilot ほか、このフォルダを読むエージェント）

中身はここの 1 か所だけにあり、リンクは指しているだけなので、直すのは
ここだけでよい。リポジトリを別の場所へ移したときは、もう一度実行する。
同じ名前のフォルダがリンクではなく本物として置いてあるときは、消さずに
そのまま残し、そのことを表示する。
